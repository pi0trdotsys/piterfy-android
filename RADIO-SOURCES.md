# Piterfy starter radio catalogue

Stream availability checked on 2026-10-16. These are public broadcasts; availability and regional rules are controlled by each broadcaster. The app does not proxy or record broadcasts.

18 stations are added once as editable local entries. Existing names, stream URLs and starter IDs are preserved. Deleted starter stations do not return on restart.

- RMF FM / MAXX / Classic: official playlists at https://www.rmfon.pl/n/rmffm.pls, https://www.rmfon.pl/n/rmfmaxxx.pls and https://www.rmfon.pl/n/rmfclassic.pls. HTTPS audio endpoints from those playlists are included.
- Radio ZET / Antyradio: broadcaster Eurozet CDN, https://player.radiozet.pl/ and https://www.antyradio.pl/.
- ESKA (Warsaw stream): https://www.eska.pl/, broadcaster SM CDN.
- TOK FM: https://www.tokfm.pl/, broadcaster radiostream.pl endpoint.
- Jedynka / Dwójka / Trójka / Polskie Radio 24: station list from the official player API https://apipr.polskieradio.pl/api/stacje; HTTPS HLS variants verified.
- Nowy Świat: https://nowyswiat.online/jak-nas-sluchac.
- Radio 357: https://radio357.pl/ and its public https://stream.radio357.pl stream.
- BBC World Service: https://www.bbc.com/audio and the public bbcmedia.co.uk stream.
- LBC / LBC News: https://www.globalplayer.com/live/lbc/uk/ and Global musicradio.com public streams.
- NDR 2 / NDR Info: https://www.ndr.de/service/Die-Radio-Livestream-Links,livestreams101.html; HTTPS audio endpoints verified from official M3U playlists.
